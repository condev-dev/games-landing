# 🎮 Con Dev | Web Games Landing

**Con Dev Games Landing** – A single-page showcase for five browser games, built with **HTML, CSS and Vanilla JavaScript**.
Designed with **clean spacing, a real RTL layout, hand-authored SVG artwork and smooth micro-interactions**, perfect for portfolio showcase.

> ⚡ **Portfolio-Level Project** – Showcasing Senior Front-End expertise in **RTL interfaces, responsive layout systems, inline SVG illustration and zero-dependency builds**.

## ✨ Key Features

- 🎰 **Five Games In One Grid** – Spin, Plinko, Mines, Dice and Limbo, each card linking out to its own published domain
- 🎨 **Inline SVG Artwork** – Every tile, card illustration and arrow is hand-authored SVG, with no image files and no icon font
- 🧱 **A Grid That Folds** – Six columns on desktop, four on tablet, one on mobile, with the first two cards spanning wider
- 🌑 **Dark Showcase Panel** – The hero pairs the copy with a dark panel that previews all five games in a 3-column tile grid
- 🧲 **Sticky Header** – The header picks up a blurred backdrop and a hairline border the moment the page scrolls
- 🎯 **Real RTL** – Built right-to-left from the start, using logical CSS properties, Persian copy and Persian digits
- 📱 **Mobile First** – Sizing and tap targets start from the small screen and grow into the desktop layout, not the reverse
- ♿ **Accessible Markup** – Skip link, aria labels, a visible focus ring and a reduced-motion mode
- 📊 **Numbered Ledger** – The behind-the-scenes section lays the build principles out as numbered rows
- ⚡ **No Build Step** – Plain HTML, CSS and JavaScript, self-hosted-free Google Fonts and zero dependencies

---

## ⚙️ How It Works

1. The header stays pinned and gains its border as soon as the page scrolls
2. The hero explains the offer and points you at the games grid or the contact block
3. Every card in the grid opens that game on its own domain in a new tab
4. The behind-the-scenes ledger sums up the three build principles
5. The contact block links to the resume and to Instagram, and the footer collects the rest of the social links
